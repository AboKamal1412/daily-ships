# Image credits and licences

Every photograph in `assets/images/` comes from
[Wikimedia Commons](https://commons.wikimedia.org/). The licence shown for each
file is the one stated on its Commons description page when the images were
retrieved on **13 November 2026** (read through the Commons API). Commons pages
can change; if you redistribute this application, re-check the linked pages.

**Changes made to every image:** scaled down to 800 pixels wide and re-encoded
as JPEG (quality 80). Nothing else was altered. Inside the app a photo may be
shown cropped to fit the card.

The images are compiled into `daily-ships.exe`. If you pass the executable on
to anyone else, pass this file on with it: the Creative Commons licences below
require the attribution and licence notice to travel with the images. The app
also prints a short credit line on each photo.

## Replacing or adding images

1. Put a JPEG (`.jpg` or `.jpeg`, about 800 px wide) in `assets/images/`.
2. Point the ship's `"image"` field in `assets/ships.json` at the file name and
   update `"image_credit"` (keep it under about 80 characters).
3. Add or update the row in this file with the author, licence and source.
4. Rebuild with `cargo build --release`. `build.rs` embeds whatever is in the
   folder; `cargo test` checks that every ship's image is present and decodes.

Only use images you have the right to redistribute, and record the licence
exactly as the source states it. Never label an image public domain unless the
source does.

## Fonts

No fonts are bundled. The app loads Segoe UI and Georgia from the Windows font
folder of the machine it runs on.

## Software

The Rust crates this project depends on (egui/eframe, image, serde, winit,
glutin and their dependencies) are open source, almost all under the MIT and/or
Apache-2.0 licences. List them with `cargo tree`; their licence texts are in
each crate's source under `%USERPROFILE%\.cargo\registry\src`.
